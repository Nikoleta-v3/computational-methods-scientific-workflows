This exercise integrates the workshop tools into a complete research workflow.

You will create a small repository, track changes with Git, publish the work on
GitHub, and open a pull request.

## Goals

- Create a repository for a small research project.
- Add project files and track changes with Git.
- Commit changes with clear messages.
- Push the repository to GitHub.
- Open a pull request and review the proposed changes.

## Walkthrough

1. Create a new project folder.
2. Add a small script, README, and any supporting files.
3. Initialise a Git repository.
4. Stage and commit the first version of the project.
5. Create a GitHub repository.
6. Connect the local repository to GitHub.
7. Push the local commits.
8. Create a branch for a small change.
9. Commit and push the branch.
10. Open a pull request on GitHub.

## Reflection

- What information should be included in the README?
- What makes a commit message useful?
- What should reviewers be able to understand from the pull request?
- Which parts of the workflow help make the project reproducible?

## Learning objectives

By the end of this exercise, you will be able to:

- create a repository for a small research project
- track changes with Git
- push local work to GitHub
- open a pull request and review the proposed change
