##  Module 1 : Computational Methods
---

Computational research involves much more than writing code. Modern research
requires tools for developing software, tracking changes, collaborating with
others, organising projects, and running computational experiments efficiently.

In this module, you will learn the essential tools that support reproducible,
collaborative, and maintainable computational research.


## Learning objectives 🎯 📚 ✅

By the end of this module, you will be able to:

- navigate your computer confidently using the command line
- use Git to track and manage changes to your work
- collaborate using GitHub
- organise computational research projects following good software practices
- recognise common approaches to parallel computing in Python and C++

### Part II

In the second part, we will return to the same running example and explore how
it can be parallelised. Through a series of demonstrations, we will implement
parallel versions using Dask in Python and MPI and OpenMP in C++.

The goal is not to provide a comprehensive introduction to parallel computing,
but to expose you to some of the most commonly used tools, demonstrate how they
are applied in practice, and provide a foundation for further learning.

## A note about this module 💡 ℹ️ 📝

These topics covered here cannot be mastered in a single workshop.

The goal is to introduce the core ideas, give you hands-on experience with the
tools, and provide a foundation that you can build on in your own research.

The material is based on established practices from the research software
engineering community and from researchers who develop computational methods and
software as part of their everyday work.
